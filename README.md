# Data Engineering with AWS

Material e projetos desenvolvidos durante o curso **Data Engineering with AWS** da Udacity.

## Estrutura

- `data_engineer_with_aws/cloud_data_warehouse/` — notebooks e projeto de data warehouse na AWS Redshift (criação de cluster, ETL paralelo, design de distribuição de dados)
  - `data_warehouse_module_project/` — projeto completo: `create_tables.py`, `etl.py`, `sql_queries.py`
- `data_engineer_with_aws/spark_and_data_lake/` — exercícios de Spark e Data Lake na AWS
- `notes.txt` — anotações sobre os datasets usados (buckets S3, regiões)
